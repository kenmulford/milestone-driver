The branch that reaches this file belongs to the caller, which resolves `integrationGranularity` from the profile at step 1 and only then reads it (`skills/solve-issue/SKILL.md (Resolved from the profile at step)`). Reaching this file therefore means the key resolved to `"milestone"`. `### Clauses` below is the complete set of per-step deltas that mode applies to the caller's pipeline; the branch model, the integration-commit trailer format, and the resume query are `${CLAUDE_PLUGIN_ROOT}/skills/solve-milestone/milestone-granularity.md`'s.
